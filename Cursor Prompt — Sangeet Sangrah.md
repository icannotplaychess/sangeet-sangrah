# Build "Sangeet Sangrah" — A Marathi Music Knowledge Archive

Create a polished, production-quality web app called **"संगीत संग्रह" (Sangeet Sangrah)**.

The concept is:

> **Wikipedia for Marathi music, poetry and musical culture.**

It should be an editorial knowledge platform dedicated exclusively to **Marathi music, Marathi poetry, Marathi साहित्य, artists, composers, lyricists, singers, songs, films, folk traditions and musical history**.

The site should feel like a **beautiful digital archive**, not like a traditional Wikipedia clone.

---

# 1. VISUAL DIRECTION

Use the attached reference image as the primary visual inspiration.

The reference has:

- Almost-black midnight background
- Extremely minimal layout
- Huge editorial serif typography
- Very high-contrast typography
- Large amounts of negative space
- Muted blue/grey text
- Thin cyan/teal borders
- Small uppercase/monospace navigation text
- Rounded pill-shaped buttons
- Subtle glow around interactive elements
- Sophisticated magazine/editorial atmosphere
- Almost no unnecessary decoration
- Typography doing most of the visual work

Translate this aesthetic into a **Marathi/Devanagari editorial archive**.

Do NOT make it look:

- like a generic Indian website
- like a Bollywood fan site
- like a Wikipedia clone
- overly colorful
- overly traditional
- like a government cultural portal
- like a generic AI-generated website
- like a dashboard

It should feel closer to a **luxury digital magazine + cultural archive + music encyclopedia**.

# 2. TYPOGRAPHY

Typography is one of the most important parts of the design.

The large typography should imitate the **high-contrast editorial serif typography in the reference image**.

Use an elegant, dramatic Devanagari serif font for Marathi.

Preferred approach:

- Use a high-quality Devanagari serif such as **Noto Serif Devanagari** or **Tiro Devanagari Marathi**
- Pair it with a high-contrast editorial serif for Latin text
- If the selected Devanagari typeface has an italic/oblique variant, use it for large hero statements
- Otherwise create the same visual feeling through weight, spacing and scale rather than using a completely different font

The typography should have:

- enormous headlines
- thin/high-contrast strokes
- elegant curves
- generous line height
- dramatic scale differences
- restrained letter spacing

Use monospace typography for tiny interface labels such as:

`संग्रह`

`शोध`

`लेख`

`क्विझ`

`आजचा तथ्य`

`विषय`

`अधिक वाचा`

Do not use excessive font weights.

The website should primarily use **2–3 typefaces maximum**.
